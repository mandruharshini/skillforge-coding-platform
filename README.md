# SkillForge Coding Platform

Flutter app for adaptive coding assessments and skill development.

## Included
- Student / Teacher role switch
- 3D-style animated dashboard
- Adaptive assessment screen
- Topic mastery and skill profile
- Practice recommendations
- Teacher command center
- Responsive Flutter Web layout

## Run
flutter pub get
flutter run -d chrome

Backend services (auth, secure code execution, database and real-time updates) are intentionally separated for the next phase.
